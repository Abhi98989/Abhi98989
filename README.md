### 🧠 Core Competencies: Android & Multi-Platform

Here is how I approach modern app development:

* **📱 Multi-Platform Architecture:** Building apps that share 95% of code across Android & iOS but adapt strictly to platform-specific guidelines (Material 3 for Android, Cupertino for iOS).
* **⚡ Native Android Integration:** Utilizing **Method Channels** to bridge Dart with native Android APIs (Kotlin/Java) for accessing device hardware like Bluetooth, Sensors, and Background Services.
* **🏗️ Clean Architecture:** Implementing **MVVM** or **Clean Architecture** patterns to separate business logic from UI, ensuring apps are testable, maintainable, and scalable.
* **🚀 Performance Optimization:** Profiling Android apps using **DevTools** to eliminate UI jank, optimize memory usage, and reduce app bundle size for faster downloads on the Play Store.
